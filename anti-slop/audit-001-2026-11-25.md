# Anti-slop copy audit 001 — 2026-11-25

Scope: every string shown to a visitor in the browser port of LibDesk. Method:
rendered text captured from all 11 screens on the live deployment (login,
librarian dashboard, catalog, book detail, members, member detail, circulation,
insights, reports, settings, student dashboard, my loans, student profile),
plus conditional strings read from `views.js` and `app.js` (toasts, empty
states, dialog labels, validation messages). SQL displayed behind the report
cards is code, not prose, and is out of scope.

Priority follows the rule tier: Hard Gate = HIGH, Purpose-Gate = MEDIUM,
Quality Locks = LOW.

## Findings

1. **HIGH — R-02** — The login tagline contains an em dash: "Catalog, members, circulation, and reports — connected to the same live records, ready when the doors open." **Source conflict (R-37):** this sentence is inherited word-for-word from the original Flask template, which is your own writing. Name the character and the rule here so you can decide: keep it as your voice, or let me replace it with a period or comma.

2. **HIGH — R-02** — The app footer contains an em dash: "LibDesk 2.0 — browser version · discrete mathematics final project". This line was written during the port, so there is no source conflict.

3. **HIGH — R-02** — The em dash is used as an empty-value placeholder in data cells: `—` for a missing borrower, a missing due date, an unreturned loan date, and null report values (`util.datefmt`, `views.js` book detail and reports). A placeholder is text too, and R-02 forbids the character.

4. **HIGH — R-02** — Number mismatch: "1 different titles read" on the student dashboard. The count is singular but the noun is plural, so the sentence does not read as human-written.

5. **LOW — R-36** — "Live copy status, not a stored counter." uses the tailing-negation pattern (state X, then deny Y). It is a single instance and the contrast is defensible, but it is a known AI rhythm tell.

6. **LOW — R-36** — "The same transactions that run the desk, read back as collection signals." opens Insights with an abstract, actorless frame before saying what the screen shows.

7. **LOW — R-36** — "which is how the catalog surfaces related authors it would otherwise miss." gives an abstraction a human verb ("surfaces", "miss") and uses product jargon where a plain statement would do.

## Passed checks

- **R-15:** CTAs are specific to the action (Issue a loan, Add book, Return, Save settings, Update password, Sign out). No "Get Started / Learn More / Try Now / Explore / Discover".
- **R-16:** no buzzwords from the forbidden list and no empty AI vocabulary found in the rendered copy.
- **R-17 / R-36:** every number on screen comes from the seeded records or a live computation (40 titles, 28 open loans, 12 overdue, 270 states, 1,075.00 estimated fines). No fabricated statistics or performance claims.
- **R-18 / R-38:** no testimonials. Member and book names are the seeded demo records, not invented social proof.
- **Quotation marks:** single quotes are used only around book and member names in toasts, which is a legitimate use.
- **Typographical check:** en dashes appear only in "Title A–Z", "Author A–Z", and "Active member–title pairs", where they mark a range or a compound. R-02 bans the em dash, not these, so no finding was raised.
- **Voice:** the copy is concrete and varies in length. Lines such as "Nothing overdue. The desk is clear." and "Grow this title's stock." read as written by a person, not padded by a model.
